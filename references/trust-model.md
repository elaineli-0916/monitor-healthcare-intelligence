# 可信度模型

## 来源评级

| 等级 | 含义 | 示例 |
|---|---|---|
| A | 直接、可问责的一手发布方 | 监管机构、政府、交易所、公司官方渠道、原始论文发布方 |
| B | 具备编辑或数据库管控的专业二手来源 | 成熟行业媒体、专业数据库、主流财经媒体 |
| C | 聚合、转载、观点导向或来源不确定的发布方 | 聚合平台、转载账号、自媒体、无署名研究观点 |

初始来源注册表使用保守的规则化评级。`rating_status: needs-review` 视为临时状态。

## 证据状态

| 状态 | 用途 |
|---|---|
| `primary` | 链接的发布方是该事件的第一手来源 |
| `secondary` | 该条目报道或转载了另一方的消息 |
| `corroborated` | 两个或以上真正独立的来源相互印证；V1 中不自动实现 |
| `unverified` | 无法核实来源或事实 |

## ByDrug 规则

ByDrug 是一个聚合平台。不要自动将所有 ByDrug 条目评为 C 级。当页面标明发布方或链接到原文时：

1. 保留 ByDrug 详情页 URL。
2. 保留原文 URL（如可用）。
3. 赋予该发布方的临时来源评级。
4. 证据状态保持为 `secondary`，除非链接的发布方可证明是第一手来源。

## 高风险规则

不得仅仅因为专业媒体来源报道过，就将金融、监管、安全、临床或政策类声明视为已核实。应优先通过监管机构、公司公告、临床试验注册库、论文或交易所通知进行确认。

## 摘要展示

每个事件必须展示：

- 可信度等级；
- 证据状态；
- 所有贡献来源的名称；
- 所有贡献链接；
- 不确定性或无法获取的说明。
